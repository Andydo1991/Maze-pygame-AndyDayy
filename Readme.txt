This text show how to use this game in your own computer. 
note this things will not work on MacBook or something from apple company!!!

1. Download the least release python from this website (https://www.python.org/downloads/)
2. Next open up the file you just download and then install it
3. Next download pygame from this website when you finish downloading open it and install
4.    In your window pc open up “command prompt” next text in this command (“ python3 -m pip install -U pygame —user”) then press “enter or return” on your laptop or pc.
5. To see it work or not type this text in “command prompt” (“ python3 -m pygame.examples.aliens”) if it show up a window then it work.
6. Them download file “main.py and data” in the git hub, then create a folder and put 2 things in that folder.
7. Then open up the file name “main.py” then run it
8. Use buttons “A”W”S”D” to control the character in the game You will have 60 second to eat much of the food in the maze as you can.
